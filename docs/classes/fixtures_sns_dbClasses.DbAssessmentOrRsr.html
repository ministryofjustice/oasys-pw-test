    Class DbAssessmentOrRsr

    This module contains the classes used to extract data from the OASys database.

    DbAssessmentOrRsr contains the data used to generate expected message content, mostly from oasys_set and offender_rsr_scores. DbSns contains the actual messages from the sns_message table.
